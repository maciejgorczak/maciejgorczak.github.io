This is the first note. I'm carving out a small, quiet space here to think
out loud — mostly about AI platforms, data, product and engineering, and
occasionally whatever rabbit hole I've fallen into lately.

## How this works

Each note is just a Markdown file. To publish a new one I:

1. Write `notes/posts/<slug>.md`
2. Add a line to `notes/posts.json` with the title, date and a one-line summary

No build step, no CMS — the page renders the Markdown in the browser. That's
deliberate: the less friction between a thought and a published note, the more
likely I am to actually write.

> A claim with no cited artifact is unverified by default.

You can write the usual things — **bold**, *italic*, [links](https://example.com),
lists, and code:

```js
const note = { idea: "write it down", friction: 0 };
```
